# fastest-primes — AIProve entry

Count primes <= N (1 <= N <= 5,000,000). Odd-only sieve of Eratosthenes in C.

## Build

```sh
make
```

## Run

```sh
echo 1000000 | ./primes   # -> 78498
```

Run command: `./primes` (or `./run.sh`). Reads N on stdin, prints the count on stdout.
